Branch Out

A puzzle game about Git branches. Type Git commands until your commit graph matches the goal. The game simulates Git in your browser; no real repository is touched.

Levels

    $

    Solved!

    Commands you can use
    • git commit or git commit -m "message"
    • git branch, git branch <name>, git branch -d <name>
    • git switch <name>, git switch -c <name> (or git checkout, git checkout -b)
    • git merge <name>
    • git log --oneline, git status
    • hint, undo, reset

    Use the up and down arrow keys to recall earlier commands.

    Part of git-in-claude, created by Chris Minnick for Chapter 9 of Claude Code For Dummies (Wiley).
